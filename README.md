# Malik Cattle & Farmhouse

Premium static website for the supplied Malik Cattle & Farmhouse Facebook identity, developed for `probuilderoffical/malikcattlefarmhouse`.

## Positioning

The website reflects the research conclusion that this is a property/land marketing business in Gadap Town, Karachi, promoting land for farmhouse, cattle-farm, picnic-farm, fruit-farm and related rural uses. It intentionally does **not** present livestock inventory, Qurbani animals, unverified WhatsApp details, stale promotional pricing, legal/approval claims, fake reviews, or invented business statistics.

## Design direction

Approved direction: **Option 2 — Land & Legacy**

- Woodland Green `#263F2F`
- Charcoal Soil `#22241F`
- Warm Cream `#F3EBDD`
- Sandstone `#D8C5A8`
- Saddle Brown `#865A36`
- Meadow `#6F9738`
- Burnished Brass `#B58A3A`
- Headings: Manrope
- Body/UI: Plus Jakarta Sans

## Run locally

No build step is required.

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
